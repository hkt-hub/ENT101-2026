ENT101 — Hafta 3–4 PWA

BU ZIP'İ GITHUB'A ZIP OLARAK YÜKLEMEYİN.
ZIP'i bilgisayarınızda açın ve içindeki dosyaları repository içindeki hafta3-4 klasörüne yükleyin.

Gerekli dosyalar:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png
- .nojekyll

Önceki Hafta 1–2 ile aynı mantık:
repository/
  hafta1-2/
    index.html
    manifest.webmanifest
    sw.js
    iconlar...
  hafta3-4/
    index.html
    manifest.webmanifest
    sw.js
    icon-192.png
    icon-512.png
    .nojekyll

GitHub Pages ayarı:
Settings → Pages → Deploy from a branch → main → /(root)
